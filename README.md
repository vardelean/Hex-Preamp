# Hex-Preamp
A  GK3 compatible hexaphonic pickup preamp

## Design Considerations

The purpose of this project is to make a replacement board for a Boss GK-3 Kit for hexaphonic pickups.

The schematic design is based on the original GK-3 Kit schematic as published by Boss in their service manual.
The main differences from the original GK-3 Kit design are:

- Better quality opamps (lower noise, lower distortion and lower power consumption)
- Adjustable gain for each string
- Adjustable gain for the guitar’s main pickups
- Selectable input impedance for the guitar’s pickups to accommodate SC and HB pickups
- Selectable input capacitance for the guitar’s pickups to emulate different cable lengths
- Single volume control for both Guitar and Synth output levels
- Balance control to adjust levels between the Guitar and Synth
